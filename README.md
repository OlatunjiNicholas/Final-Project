# Project Overview
This project focuses on API testing of the Swagger Petstore API using Postman.
The objective is to validate the functionality, response status codes, response body, response time, and behavior of the available API endpoints.

## API Under Test
Swagger Petstore API
https://petstore.swagger.io/

## Tools Used
●Postman
●GitHub
●Swagger Petstore API

## Testing Scope
The following API modules were tested:

## Pet
- Add a new pet
- Update an existing pet
- Find pets by status
- Find pets by tags
- Find pet by ID
- Delete a pet
- Upload an image for a pet

## Store
- Retrieve pet inventory
- Place a new order
- Find an order by ID
- Delete an order

## User
- Create a new user
- Create multiple users
- Retrieve user details
- Update user information
- Delete a user
- Login user
- Logout user
